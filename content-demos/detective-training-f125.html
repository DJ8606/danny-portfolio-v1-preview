1. 前端展示总成 (HTML 骨架)
站台一 · 实体存在性依据 · 内存 DOM 树
骨架套娃
像钢筋梁柱与空纸箱，决定页面里“到底有什么”。尖括号标签嵌套在内存中长成 DOM 树。
1.1 标签嵌套与 DOM 树内存生成 展开档案 ➔
1.2 语义化零件 (div 容器, button 按钮, input 输入框) 展开档案 ➔
1.3 经典断点：标签漏闭合排版全崩 🚨 典型事故
🏗️ 物理隐喻与装配位置
大楼的建筑毛坯骨架。HTML 决定现场有几扇门、几面墙。没有骨架，后面的涂料（CSS）和机械臂（JS）根本没有着力点。
🛡️ AI 时代的祛魅心法
面对 AI 生成的几百行 HTML 标签，千万不要被密密麻麻的尖括号吓退。它只有最质朴的三级套娃关系：外层 html ➔ head(隐形配置) / body(肉眼可见) ➔ 内部组件盒子。
🛠️ 对应 F12 装备与三步勘验【中文环境对照】

② 鼠标点击页面零件，观察左侧 DOM 树 是否高亮定位到标签；
③ 如果树上搜不到该节点，说明该零件被条件逻辑剔除或未被正确渲染。

涂装工与包装箱。Margin(邻里间距) ➔ Border(纸箱外壳) ➔ Padding(防震泡沫) ➔ Content(箱内实物)。天生是大喇叭广播覆盖。

4. 海陆货运航道 (Network / HTTP)
站台二 · 网络传输网络 · 状态码旗语与集装箱面单
快艇信使
穿梭在客户端与远端机房之间的物流网络。标准集装箱分为面单、报关头与箱内实物。
4.1 集装箱报文结构 (URL, Headers 标头, Body 实体) 展开档案 ➔
4.2 状态码旗语 (200 成功, 304 缓存, 404 迷路, 500 后厨崩溃) 展开档案 ➔
4.3 经典断点：接口少打字母 404 迷路触礁 🚨 第三关故障
🏗️ 物理隐喻与旗语法则
水上快艇航道。200 OK（货已顺利靠岸）；304（旧货没变复用缓存）；404（找错码头暗礁迷路）；500（后厨失火烧锅）。
🛡️ AI 时代的祛魅心法
弹窗说“网络异常”，不要以为是网线断了。90% 的网络错误只是前台把 URL 地址或者 HTTP Method（GET/POST）写差了一个字母。

② 触发页面动作，看雷达列表里弹出的请求；
③ 点开该请求看 Headers (请求标头) 中的 Request URL 是否拼错，以及状态码是否变红。

5.3 经典断点：字段不符读出 undefined 变 NaN 🚨 第四关故障
🏗️ 物理隐喻与接口法则
后厨与前厅的传菜口。不管后厨用 Python 还是 Java，送出来的都必须是一张规范的 JSON 小纸条 {"total_price": 99}。
🛡️ AI 时代的祛魅心法
金额显示 ¥NaN，初学者常常以为是计算机硬件算错了。其实是前端读了不存在的字段名（如 res.price 取出 undefined），和数字相加自然成了 Not a Number (NaN)。

③ 核对键名，将前端代码的取值路径（如 res.total_price）与真实键名对齐。

💡 它到底是什么？（解剖结构与本质）
本质：它是浏览器把 HTML 骨架和 CSS 样式解析后，当前此刻存放在内存 RAM 里的“活体 DOM 树”。
解剖结构：
• 左侧主视窗：可折叠展开的实时 HTML 标签树，带节点高亮与路径导航；
• 右侧 Styles 栏：从上到下按权重排列的层叠样式规则，带勾选框；
• 右侧 Computed 栏：浏览器最终执行完所有计算后的精准像素尺寸，底部配有同心四层盒模型示意图。
⚡ 它能做什么？（特工超能力清单）
  • 双击实时修改任何文本与标签：现场改字、换类名，回车立刻在屏幕上看到视觉反馈；
  • 实时开关/注入 CSS 样式：点击勾选框切换 display、color，或现场写新样式测试排版；
  • 强制激活交互伪类：点击 :hov 强制锁定 :hover、:active 状态，从容调试悬停样式；
  • 盒模型尺寸即时调节：直接双击盒模型图中的 Margin/Padding 数值进行微调；
  • 拖拽重排与临时剔除：直接按 Delete 键删除遮挡屏幕的恶心弹窗或遮罩层。
🚫 绝对不可以做什么？（新手最大认知误区）
  • ❌ 绝对不能永久修改服务器上的代码：你在这里改的所有字和样式，只存在于当前这台电脑的临时内存中！按一下 F5 刷新立刻还原；
  • ❌ 不能绕过服务端的真实业务鉴权：把按钮的 disabled 强行删掉，只要后厨有安全校验，点击依然无法真正扣款发货；
  • ❌ 无法直接点选 Canvas 内部绘制的具体图形：Canvas 是一整张扁平像素画板，Elements 只能看到外层标签，抓不到画笔画出来的具体形状。
🎯 老鸟特工秘籍 (Pro Tips)
快捷键 Ctrl + Shift + C（Mac: Cmd + Shift + C）开启“元素瞄准镜”，鼠标在网页上悬停即时透视对应盒模型，点击直接在树上高亮定位，找按钮找盒子只需 1 秒！
💡 它到底是什么？（解剖结构与本质）
本质：它是前端 JavaScript 运行时的“实时听诊器与 REPL 交互命令行终端”。
解剖结构：
• 消息日志流：白色普通日志 (log)、黄色告警 (warn)、刺眼红字报错 (error)；
• 过滤工具条：支持按报错级别过滤，勾选 Preserve log 跨页面跳转不丢日志；
• 命令行输入框：底部的 > 提示符，直接接入当前网页的 JS 运行时主线程。
⚡ 它能做什么？（特工超能力清单）
  • 直接执行任意 JS 代码：在命令行输入任意表达式或函数调用，立刻在当前页面生效；
  • 神级变量 $0 隔空取物：代表你在 Elements 里选中的当前元素，输入 $0.click() 直接代码触发点击；
  • 结构化输出利器 console.table()：把杂乱的 JSON 数组一秒转成漂亮的网格表格呈现；
  • 一键拷贝内存对象 copy()：在控制台输入 copy(data)，直接将内存对象完整塞入系统剪贴板；
  • 精准顺藤摸瓜：点击任何红字右侧的 文件名.js:行号，一秒瞬移到案发源码位置。
🚫 绝对不可以做什么？（新手最大认知误区）
  • ❌ 无法撤销已经产生的执行副作用：执行了删除或覆盖变量的操作，无法像按 Ctrl+Z 一样回退；
  • ❌ 无法直接访问封闭作用域内的局部变量：被函数闭包封装在内部的变量，除非在代码行打上断点暂停，否则外界控制台隔空摸不到；
  • ❌ 报错不会惩罚你：红字是机器在向你极其严肃严谨地递交报修工单，看清楚报错名称（TypeError、SyntaxError）是解决问题的起点。
🎯 老鸟特工秘籍 (Pro Tips)
遇到页面假死、按键毫无反应，第一反应永远是看 Console 右上角有没有红色圆形报错图标。红字给出的永远是第一案发现场！
💡 它到底是什么？（解剖结构与本质）
本质：它是浏览器与外部服务器进行通信的“水上货运雷达与海关集装箱清单记录仪”。
解剖结构：
• 捕获控制条：红点录制开关、清空列表 🚫、Disable cache 禁用缓存、网络节流下拉框；
• 类型过滤栏：All、Fetch/XHR（专看异步接口）、JS、CSS、Img 等分类标签；
• 集装箱报文大抽屉：Headers（面单与报关头）、Payload（送过去的参数）、Response（返回的真实原文）、Timing（耗时瀑布图）。
⚡ 它能做什么？（特工超能力清单）
  • 核对每一张通信单据：检查请求 URL 有没有拼错，查看后端送回来的真实 JSON 键值对原文；
  • 模拟极端恶劣弱网：在节流栏选择 Slow 3G 或 Offline，测试弱网环境下页面交互；
  • 耗时病根拆解 (Timing)：看耗时到底是排队延迟、DNS 寻址，还是后端后厨处理耗时太长（TTFB）；
  • 一键导出与重放：右键任意请求 ➔ Copy ➔ Copy as cURL 或 fetch，直接在命令行复现问题。
🚫 绝对不可以做什么？（新手最大认知误区）
  • ❌ 抓不到打开 F12 之前的历史请求：F12 没打开时发生的通信默认是不记录的；刷新前若没勾选 Preserve log，跳转后列表会被清空；
  • ❌ 200 OK 绝不等于业务成功：200 仅代表货船顺利靠岸，至于箱子里装的是成功货单还是“密码错误”的单据，必须看 Response 原文；
  • ❌ 默认状态下无法在半路篡改传输数据：它是只读雷达，无法在快艇航行途中强行替换数据包（除非使用 Local Overrides 覆盖）。
🎯 老鸟特工秘籍 (Pro Tips)
调试数据接口时，第一时间点击顶部 Fetch/XHR 按钮，过滤掉杂乱的图片和字体请求，整个雷达站立刻只剩下核心的业务数据流！
💡 它到底是什么？（解剖结构与本质）
本质：它是浏览器专门为当前域名分配的“客户端本地储物私房箱”。
解剖结构：
• LocalStorage：持久化硬盘抽屉，容量约 5MB，关掉浏览器依然永久保留；
• SessionStorage：单标签页临时内存抽屉，标签页一关即刻自动销毁；
• Cookies：随信小纸条，每次发 HTTP 请求都会自动带上，带过期时间与安全防线；
• Storage 顶级菜单：配有一键清空全部缓存的 Clear site data 按钮。
⚡ 它能做什么？（特工超能力清单）
  • 直接查看与修改本地键值对：双击 Value 直接改值，或者手动添加测试数据；
  • 一键重置为纯净新访客状态：点击 Clear site data，瞬间抹去一切本地 Cookie 与缓存；
  • 核验 Cookie 安全防线：查看 Cookie 是否带有 HttpOnly、Secure 或 SameSite 属性。
🚫 绝对不可以做什么？（新手最大认知误区）
  • ❌ 前端 JS 绝对无法偷看带 HttpOnly 标记的 Cookie：这是浏览器防范 XSS 窃取登录态的最强防线；
  • ❌ LocalStorage 不能存放海量超大文件：容量上限通常只有 5MB，强行塞大会触发 QuotaExceededError；
  • ❌ SessionStorage 无法跨标签页共享：即便在同一个浏览器打开相同网站的两个 Tab，它们的 SessionStorage 也是完全独立的。
🎯 老鸟特工秘籍 (Pro Tips)
排查“刷新后登录态失效”或“购物车莫名清空”时，打开 Application 的 Local Storage，看看登录返回的 Token 到底有没有被代码写进抽屉里！
💡 它到底是什么？（解剖结构与本质）
本质：它是前端代码的“手术室、显微镜与慢动作回放机”。
解剖结构：
• 左侧文件资源树：展示当前页面加载的所有 JS、CSS 文件与 Source Map 原始工程；
• 中间源码阅览区：带行号的代码编辑器，底部有 {} 代码一键格式化按钮；
• 右侧断点手术台：Call Stack（调用栈）、Scope（局部/全局作用域变量）、Watch（表达式监视器）。
⚡ 它能做什么？（特工超能力清单）
  • 时间定格（断点调试）：在代码行号点击下断点，程序跑到这里瞬间暂停，让你单步逐行观察（Step over）；
  • 解压混淆乱码（Pretty Print）：点击底部的 {}，把压缩成一行的丑陋代码一秒还原为整齐多行；
  • 扒出作者原始未混淆工程（Source Map）：在左侧寻找 webpack://、vite:// 或 src/，能直接阅读作者带中文注释的原始 Vue/React 源码！
🚫 绝对不可以做什么？（新手最大认知误区）
  • ❌ 绝对看不到后端的私密源码：Sources 只能看到下载到浏览器运行的前端脚本，看不到服务器上的 Java/Python/Go；
  • ❌ 临时改动不会同步到服务器：在 Sources 里面改动代码，只对当前单次会话有效，刷新后重新下载原版。
🎯 老鸟特工秘籍 (Pro Tips)
看到别人网站上有极其炫酷的动效？打开 Sources 找到对应的 JS 文件，点击 {} 美化，或者直接右键另存为，用 VS Code 拆开学！
