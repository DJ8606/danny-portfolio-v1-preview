# DANNY · 六面网站拼装说明

## 1. 不要改动已认可的 V11 底盘

建议把本文件夹 `DANNY_Road_EXPANDED` 原样放入六面网站，例如：

```text
my-site/
  index.html                  # 六面主站
  video-road/                 # 整个文件夹
    index.html
    app.js
    assets/
    content/
    media/
```

六面入口点击“视频世界”后，让 `<iframe src="video-road/index.html">` 占满内容区。

```html
<iframe id="danny-road" src="video-road/index.html"
  title="DANNY 视频公路世界" allow="fullscreen; autoplay"
  style="border:0;width:100%;height:100%;display:block"></iframe>
```

**不要把 `app.js` 里的绘图函数复制进总站主文件；用 iframe 隔离样式、按键事件和声音状态。**

## 2. 返回总站（重要）

视频世界右上方「↩ 返回」会向父页面发送：

```js
{ source:'DANNY_ROAD', type:'DANNY_ROAD_EXIT' }
```

六面主站应监听 `message` 并关闭视频世界面板／重新显示六面入口。参考 `integration/demo-host.html`。

其他事件：`DANNY_ROAD_READY`、`DANNY_ROAD_OPEN_WORK`、`DANNY_ROAD_CLOSE_WORK`。

总站发给视频世界：

```js
iframe.contentWindow.postMessage({source:'DANNY_HOST', type:'PAUSE'}, '*');
iframe.contentWindow.postMessage({source:'DANNY_HOST', type:'RESUME'}, '*');
iframe.contentWindow.postMessage({source:'DANNY_HOST', type:'GO_TO', x:4590}, '*');
```

## 3. 内容只改配置

- `content/portals.js`：**物理入口**世界坐标和类型，保留 V11 前 18 个入口；新增 10 个 `kind: native` 入口会直接绑定场景原画的放映点，不额外覆盖一块矩形屏幕。
- `content/scenic_route.js`：连续地图的分块坐标、10 个追加旧场景的起止里程；不要只修改作品入口而重新排列背景。
- `content/works.js`：作品数据，`portal` 指向入口 `id`，`file` 写视频相对路径。单个入口可绑定多条作品，进入后通过选单切换。
- `content/radio.js`：电台名称、音频路径。留空使用现有三种合成音乐。
- `content/settings.js`：总站回链等选项。iframe 模式通常不必填 `homeUrl`。
- 不上传视频到任何外部平台；复制到 `media/video/` 即可。

**推荐让素材在编译时自动拷贝，禁止向 JS 代码中塞 mp4 的 base64。**

## 4. 稳定性和移动端

- iframe 容器桌面推荐 16:9 或占满视口；游戏内部会自适应。
- 进入本版前，总站应暂时停止背景键盘快捷键，关闭 iframe 后恢复。
- 音乐需要访客手动点击开启，不能依赖自动播放策略。
- 关闭 iframe 或退出站点时销毁 iframe，避免声音和 RAF 在不可见区域继续运行。
- 正式部署时使用 HTTPS / 正常静态服务器；直接打开 `index.html` 可用于本地测试，但浏览器对本地视频编解码仍有差异。

## 5. 拼装验收

- [ ] 六面 → 视频世界可进入
- [ ] 视频世界 → 六面可返回
- [ ] 向右驾驶和暂停正常
- [ ] 轮心、狗和场景仍保持 V11 认可状态
- [ ] 通过暖色山谷和松林的交界没有新增遮挡；新增 10 段老场景都能通过地图定位和实际开车抵达
- [ ] 进入任意入口出现作品占位和作品列表
- [ ] 把一个测试 MP4 放到 `media/video/`，填配置可播放
- [ ] Esc 关闭视频、回到公路
- [ ] 多个作品挂在同一个入口时可切换
- [ ] 本地电台配置／暂停正常
- [ ] 手机竖屏按钮可用（但建议横屏浏览）

## 6. 不在拼装阶段做的事

本版不更换角色、不重做 V11 第一段地貌、不改动那个已经验收的交界遮挡。旧的 10 个场景已经作为后续连续路线追加，画面图块和对应的世界坐标位于 `content/scenic_route.js/json` 和 `assets/world_segment_*.webp`；今后调整时务必同时更新场景图块与坐标配置。
